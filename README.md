# RedalertUE5

A personal full-3D Unreal Engine 5 RTS project inspired by Red Alert 2 and Yuri's Revenge: faithful unit identities, an RA2 visual style, capable AI opponents, and eventually games with up to eight friends.

## Current state

This repository currently contains planning documentation only. There is no Unreal project, selected engine version, playable build, finished art, or measured performance result here. Milestones describe work to prove, not completed features or delivery dates.

Start with Allies and Soviets on one simple map. Prove the visual direction with a Tesla Reactor, Rhino Tank, and Conscript together at the intended RTS camera before finishing assets. Prove two-client play and active-unit performance early; then complete a small skirmish with bots. Yuri and four/eight-player validation follow.

## Working rules

Keep project files, source art, caches, and builds on D: using explicit project-specific paths. Verify actual cache and temporary-file locations; this is not a promise of zero writes to C:. Keep generated files out of Git, and review Git LFS storage/bandwidth before uploading binary assets. See the brief for the setup gate.

Use newly created reference-based art. Do not upload raw EA assets or music. Ownership of the original games is recorded as reference availability, not redistribution permission. No license or permission grant is asserted by these documents.
