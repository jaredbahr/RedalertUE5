# Bot delivery after the final ore

An explicit ReturnCargo names one refinery. If combat destroys that refinery before deposit, the authoritative model cancels the order and preserves the cargo. Ordinary Gather orders survive a missing refinery and already resume delivery after a replacement appears. The bot's snapshot planner could rebuild for surviving cargo, but its miner loop then issued nothing when no positive ore target remained.

The existing miner slot now chooses Gather while a usable resource exists, otherwise ReturnCargo for a loaded live own Harvester. Delivery targets the nearest committed live own refinery, with stable unit ID breaking distance ties, matching the model's refinery choice. A refinery planned in the same batch is not a target. Commands still use AddCommand and authoritative Submit, with one miner intent per decision, existing rotation, five-second type/target retry, one-second decisions and four-command cap. Production, combat scheduling, model rules and headers are unchanged.

The snapshot exposes no current private miner order, so this fallback can also overlay an already waiting Gather return. Its target follows the same nearest-refinery rule; the unchanged ordinary-Gather tests remain required. Current autonomous bot code previously did not issue ReturnCargo. This fixes recovery from a supported public-model command history, without claiming that the interrupted explicit return was observed in normal autonomous play.

Prepared native cases are `BotFinalCargoPlanner` and `BotFinalCargoPublicRecovery`. The planner case covers eligibility, committed targets, nearest/tie/permutation behavior, rotation, retry, same-miner intent changes and the shared budget. The public case uses real setup, finite harvesting, explicit return, refinery destruction, rebuilding and subsequent delivery through Submit/Advance, with aggregate cargo/credit conservation. Its owner-sequence adapter makes it a snapshot-planner integration history, not a complete autonomous match. Existing ordinary-Gather tests are preserved. The portable bot runner requires all eight exact old/new groups, and the native manifest retains every old name plus the two new cases.

Independent final source review found no remaining concrete defect after repairs to the first unexecuted test draft. Planner and public-history fixtures were written by separate workers and reviewed by a different reviewer. All new tests, compilation and Unreal validation remain queued and unrun; no pass count or playable build is claimed.
