# Art direction

## Confirmed direction

Faithful RA2 unit identities in full 3D, with the original game's visual character and readable RTS silhouettes. Avoid the childish RA3-like look Jared rejected. The first evaluation happens from the gameplay camera, not only in close-up asset renders.

## First visual proof and approval gate

Build low-detail blockouts of the **Tesla Reactor, Rhino Tank, and Conscript**, shown together on a simple ground plane or test map. Use neutral, consistent lighting and a declared camera angle, height, and zoom range so revisions are comparable.

Deliver the following for Jared's review:

1. A normal RTS-camera still with all three assets together.
2. A zoomed-out still showing recognition at expected gameplay size.
3. A short motion view with tank movement/turning, infantry movement, and camera pan/zoom; simple placeholder motion is sufficient at this stage.

Pass only after Jared approves relative scale, proportions, silhouettes, faction character, and readability in these views. Record requested revisions and approved captures. **Do not finish meshes, textures, rigs, or effects before blockout approval.** Approval is not yet recorded.

## Proposed visual defaults to test

- Preserve distinctive outline and major forms before adding surface detail. Use faction color and material separation to support recognition.
- Use the RA2 in-game appearance and official reference imagery to compare form, palette, and proportions. Log the reference source for each asset; resolve conflicting depictions with Jared.
- Keep wear and fine detail subordinate to clean silhouettes at RTS distance. Test effects without obscuring units, ownership, or selection.
- Judge infantry, vehicle, and building scale as a group. Use gameplay readability as a candidate guide; do not lock realistic scale or exaggerated scale until reviewed.
- Use restrained lighting/material tests that preserve the approved RA2 character. No specific rendering features, texture sizes, polygon counts, or performance costs are approved yet.

## Reference and asset boundaries

New reference-based art is recommended. Jared's original-game ownership supports private reference access; it is not a redistribution license. Do not commit extracted EA meshes, textures, sprites, audio, music, or copied reference packs. Keep provenance and usage terms for newly created or third-party assets before sharing them.

Jared has authorized the first implementation batch, including original authored blockout modeling and reproducible scene generation with existing tools. This does not approve asset finishing: the visual blockout gate still applies. Keep editable source files and generated assets on the designated non-system drive, and pass the binary/LFS review before any binary upload.
